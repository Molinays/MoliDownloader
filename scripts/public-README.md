# MoliDowloader

Applicazione desktop per Windows per scaricare video e audio (YouTube, TikTok, Instagram e oltre 1000 siti supportati da yt-dlp), montarli con un piccolo editor e comprimerli con FFmpeg e accelerazione GPU.

> Questo repository distribuisce **solo i file eseguibili**. Il codice sorgente non è pubblico.

## Download

Vai alla pagina dell'ultima versione:

**→ [Download MoliDowloader](https://github.com/Molinays/MoliDownloader/releases/latest)**

| File | Descrizione |
| --- | --- |
| `MoliDowloader-Setup-<versione>.exe` | Installer consigliato: installa l'app e riceve gli aggiornamenti automatici |
| `MoliDowloader-<versione>.exe` | Versione portable, nessuna installazione; si aggiorna manualmente |

## Funzioni principali

- Download video fino a 4K e audio in MP3, M4A, Opus, FLAC e WAV, con playlist, sottotitoli, cookie, proxy e SponsorBlock.
- Editor: taglio, riordino, velocità, volume e fade per clip, traccia musicale, export MP4/MKV/M4A.
- Compressione in stile HandBrake: x264, x265, VP9, AV1 e encoder GPU NVENC, Quick Sync, AMF e VideoToolbox, con merge delle tracce audio e conversione sottotitoli.
- Scheda Info con sistema, GPU rilevate, test reali degli encoder e suggerimenti automatici.
- Aggiornamenti automatici dalla versione installata.

## Requisiti

- Windows 10/11 a 64 bit.
- Non serve installare FFmpeg, ffprobe o yt-dlp: sono già inclusi nel pacchetto.

## Aggiornamenti

La versione installata con l'installer controlla le release di questo repository e scarica da sola le nuove versioni. La versione portable non si aggiorna da sola: scarica il nuovo file da questa pagina.

## Note

- Scarica l'app solo da questa pagina ufficiale.
- Usa il programma per contenuti di cui hai i diritti o che la piattaforma consente di scaricare.
- Gli installer non sono firmati con un certificato commerciale: Windows SmartScreen può mostrare un avviso al primo avvio.
