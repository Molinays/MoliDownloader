MoliDowloader Portable

The standalone, no-install version. Save it anywhere, carry it on a USB drive, or run it on any Windows PC without touching the registry or requiring administrator privileges.

Download MoliDowloader Portable (.exe) Prefer the Installer?

MoliDowloader-<version>.exe · Windows 10/11 (64-bit)

Why use the Portable version?

Zero installation No setup to run, no mandatory steps. Double-click the executable and you are ready to download.
Portable on USB Put it on a USB drive or external hard disk and use it on any Windows 10 or 11 (64-bit) computer.
All engines included yt-dlp, FFmpeg, and ffprobe are already bundled inside: you do not need to configure anything.
Does not modify the registry It does not create entries in the system program list and leaves no residue in the Windows registry.

How to update the Portable version

The app will automatically notify you at startup whenever a new version is available. To update:

1. Download the new executable from this page.
2. Replace the old .exe file with the new one (or simply delete the old one and launch the new one).
3. Done! All your downloaded videos and favorite folders will remain intact.
SmartScreen warning on first launch:
Since this is an independent open-source application without a paid certificate costing thousands of euros, Windows Defender SmartScreen may show the blue "Windows protected your PC" screen.
Just click More info and then Run anyway. The software is 100% open-source and verifiable on GitHub.
